# AI Decision Flow

AI-powered visual decision workflow built with React Flow, Inngest, Node.js, Express and OpenRouter.

## Features

- Visual AI decision nodes
- YES / NO branching
- Editable decision prompts
- Customer message input
- AI-powered decision making
- Inngest workflow execution
- Dynamic workflow traversal
- Execution logs
- Workflow completion tracking

## Tech Stack

### Frontend
- React
- Vite
- React Flow
- CSS

### Backend
- Node.js
- Express.js
- Inngest
- OpenAI SDK

### AI
- OpenRouter
- Gemini 2.5 Flash

## How It Works

Customer Message
↓
AI Decision Node
↓
YES / NO
↓
Matching Edge
↓
Next Decision Node
↓
Workflow Completion
